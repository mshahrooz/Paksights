Test layout breakpoints without owning every device

Pick from more than 25 phone, tablet, laptop and desktop viewport presets, or enter a custom size. Compare up to four layouts at the same time. Every preview uses the requested CSS viewport width and height, so responsive media queries can adapt normally.

Use this tool for quick visual checks, not as a substitute for Safari, Chrome on Android, actual touch input or accessibility testing on physical devices. Device names represent approximate CSS viewport presets, not physical device emulation.

Privacy: Live URLs load directly in your browser (not through a PakSights screenshot server). Local HTML is not uploaded. Recent URLs and saved custom device presets are stored only in your browser. Third-party websites and AdSense may receive their usual requests when loaded.

Frequently asked questions

Why is a website blank or refusing to load?

Some websites prohibit embedding through X-Frame-Options or Content-Security-Policy frame-ancestors. This tool cannot bypass those rules. Select “Open website” to visit the site directly, or preview your own standalone HTML in the local HTML tab.

Does the preview simulate a real iPhone or Samsung phone?

It uses a matching or approximate CSS viewport size, not the actual device operating system, browser engine, user agent, sensors or touch hardware. Always confirm important issues on a real device.

Can I preview a site that is not published?

Yes: paste or upload a self-contained HTML file. Local code is rendered in a restricted iframe. Relative assets in separate files may not work, and scripts are off unless you deliberately enable them.

Can I save or share a preview setup?

Share setup copies a URL containing the live website and selected viewport preferences. Your locally pasted HTML is never included. Custom devices are saved locally and do not sync to another browser.
